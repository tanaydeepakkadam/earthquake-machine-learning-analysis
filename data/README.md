# Data

`usgs_all_month_2025-11-24.csv` is the USGS all-month earthquake-feed snapshot used in the original academic analysis.

Source:
https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/all_month.csv

The dataset was documented in the academic project form as Public Domain data.

The live USGS all-month feed changes continuously, so this repository keeps the historical snapshot used by the model for reproducibility.
